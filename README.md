# StudyPilot AI Final

面向自主学习、复习和知识理解的学习工作台。

## 功能
- 课程与进度管理
- TXT / Markdown / CSV 学习资料导入
- 本地自动摘要
- 根据资料自动生成练习
- 答题解析与错题本
- 基于资料的本地检索答疑
- 学习笔记
- 学习统计
- 学习数据 JSON 导出
- 手机 / 桌面响应式界面
- LocalStorage 本地保存

## 部署
把 index.html、styles.css、app.js、README.md 上传到 GitHub Pages 仓库根目录即可。

## AI 后端
当前版本无需 API Key 即可运行。若需要真正的生成式 AI 总结、问答、自动出题，应增加服务端 API 代理，并把 AI API Key 仅保存在服务端环境变量中，切勿写入前端 JavaScript 或公开 GitHub 仓库。

## 使用边界
用于学习、复习、练习与知识讲解；不用于绕过课程平台限制、伪造学习活动或代替本人参加考试。
